# Long Ascent

An idle game for short check-ins. A few families hold a ford and a timber keep; five ages later their descendants
leave for another world. Buildings, a research tree with one doctrine per age, heroes and expeditions, a great work
and a trial in every age, and a legacy that carries over to the next world.

- Web app: https://jpvanacor.github.io/long-ascent/
- Android app: https://github.com/jpvanacor/long-ascent/releases/latest/download/long-ascent.apk

The game keeps its progress on the device. Menu, Save gives a text copy of the save that can be loaded on another
device (the web app and the Android app keep separate saves).

## How it is put together

There is no build step: GitHub Pages serves the files as they are.

| Path | What it is |
| --- | --- |
| `index.html`, `css/style.css` | The page and its five age skins |
| `js/core.js` | Rules and data, no DOM. Runs in the browser and in Node |
| `js/scene.js` | The illustrated settlement, drawn on a canvas |
| `js/ui.js`, `js/fx.js`, `js/audio.js` | Interface, animations, sound |
| `js/icons.js` | The icons, generated by `tools/icons.js` |
| `audio/` | Music and sound effects, generated by `tools/music/build.js` |
| `sw.js`, `manifest.webmanifest`, `icons/` | Install and offline support for the web app |
| `android/`, `capacitor.config.json`, `scripts/` | The Android wrapper (Capacitor) |
| `tools/` | Pacing simulator, screenshot and play-through tests, asset generators |

## How versions work

`APP_VERSION` in `index.html` is the version. GitHub Pages publishes the web app about a minute after each push. The
Android workflow builds a new APK from the same files and attaches it to a release named after `APP_VERSION`; the
Android app then shows a bar saying a new version is ready. Raise `CACHE` in `sw.js` together with `APP_VERSION`.

The Android signing key (`android/app/long-ascent-release.p12`) is kept in the repository so each build can update
the previous install. Only install APKs from this repository's releases.

## Working on it

```
npm install
npm run serve            # the game at http://127.0.0.1:8123/
npm test                 # the scripted players: how long each kind of player takes to finish
node tools/sim.js cal    # refit the prices to the target pace, then: node tools/freeze.js
node tools/shot.js       # phone-sized screenshots of every screen (needs Playwright and Chrome)
node tools/bot.js        # a robot plays a whole world through the real buttons
```

The music is written as note lists and can be rendered again with `node tools/music/build.js`; see `CREDITS.md` for
where the instrument samples come from.
